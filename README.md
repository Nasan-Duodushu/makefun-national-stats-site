UK in Numbers — the United Kingdom, measured: population, the economy, jobs and prices, with every figure sourced and dated. A static site that runs offline in the browser, on desktop and phone.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
